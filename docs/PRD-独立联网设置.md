# 独立联网设置

2026-10-11：三项移植工作的第三项；完成验证后独立提交推送。

## 使用方式

供应商和 Key 的编辑抽屉增加“联网方式”。供应商默认跟随系统设置；Key 默认沿用供应商设置。两处均可改为直连或指定网络代理，Key 的单独选择优先。指定代理支持 HTTP 和 SOCKS5，可填写独立用户名、密码；密码默认遮挡，地址不接受混入账号信息。

```text
+--------------------------------------------------+
| 编辑供应商 / 编辑 Key                            |
| 名称 / 地址或密钥                                |
| 联网方式 [跟随系统设置 / 沿用供应商设置 v]        |
|          [直连] [指定网络代理]                    |
| 指定时展开：                                     |
|   代理地址 [http://127.0.0.1:7897]                 |
|   用户名（可空） [                 ]             |
|   密码（可空）   [*****************]             |
| 模型 / 其他设置                                  |
|                                     [取消][保存] |
+--------------------------------------------------+
```

沿用现有 MiSans、主题颜色和 4/8/12 像素间距；英文提示换行。仅在指定代理时显示地址和凭据，切换选项时保留未保存的输入；关闭未保存草稿沿用抽屉确认流程。不增加入场动画。

## 生效与兼容

- 配置 schema 7 新增可选 `network_proxy`，旧配置默认继承。保存成功后新的请求与后续重试使用新设置；切换 Key 时，尚未输出的请求沿用现有即时改投流程。已经输出的请求继续使用原连接。
- 系统模式保留现有环境变量、Windows 系统代理和绕过规则；直连始终直接连接，指定代理始终使用填写的代理，不受系统绕过列表影响。支持 `http://`、`socks5://`、`socks5h://`；省略协议按 HTTP 处理。地址最多 2048 字符，只包含主机与有效端口；用户名和密码各最多 255 UTF-8 字节，不接受控制字符。
- 每次尝试按供应商与 Key 的快照选择出口。不同代理地址、协议或凭据使用独立连接池，直连亦独立；最多保留 16 个闲置池，使用中的池在响应释放后才可回收。HTTP、Codex 系统 TLS、Claude 指纹 TLS 均保持原有传输方式和头序。
- 获取模型、保活和绑定供应商的独立准备任务均使用对应设置；准备任务在开始时固化快照，准备页获取模型也解析当前目标。自定义准备地址继续跟随系统设置。代理失败不回退直连；错误只显示链路类别，不包含代理地址、账号或密码。
- 配置克隆、相等比较、持久化及保存失败回滚包含新设置。凭据随现有配置保存，不写入客户端配置、请求日志或统计记录。

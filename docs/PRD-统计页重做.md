# 统计页重做

## 范围

参考 [magpie](https://github.com/yetone/magpie) 的 Usage / Requests 页（2026-10-11 阅读 main），重做本项目统计页。费用按模型公开价估算，支持用户修改单价；货币为美元。统计仅覆盖通过本代理的用户请求。

布局草图：

```text
+------------------------------------------------------------------+
| 统计                                    刷新       模型单价       |
| 用量分析                 缓存详情                 实时请求         |
+------------------------------------------------------------------+
| 今天 / 7 天 / 30 天 / 全部 / 自定义         起始日期 -> 结束日期    |
| 客户端 [全部]   供应商 [全部]   模型 [全部]   Key [全部]           |
+------------------------------------------------------------------+
| 已结束请求      总用量           缓存命中率        估算费用        |
| 普通输入 / 输出 / 缓存读取 / 缓存写入 / 思考用量 / 响应速度       |
+------------------------------------------------------------------+
| 趋势 [用量 / 费用 / 请求 / 速度]       拆分 [模型 / 供应商 / ...] |
|                                                                  |
|             堆叠柱状图                        占比排行           |
+------------------------------------------------------------------+
| 活跃日历：最近 53 周，每格一天，点选查看当天                      |
+------------------------------------------------------------------+
| 请求明细                         状态筛选              导出 CSV  |
| 时间 / 模型与供应商 / 结果 / 用量 / 命中率 / 费用 / 耗时          |
|                                               上一页 / 下一页    |
+------------------------------------------------------------------+
```

沿用 WPF-UI 主题、字体与圆角；图表采用语义颜色，适配深浅主题和窄窗口。数据刷新不播放入场动画，保留筛选和滚动位置；加载提示固定保留 12 个布局单位（2 高的进度条及 10 的下间距），仅初次加载、切换筛选和手动刷新时显示。

界面按变化更新：数字仅通知变化的字段，用量细分、排行、日历和请求明细按固定身份复用条目，集合只处理增删与排序；未变化的图表数据和月份标签保持原对象。明细以通道及请求编号共同识别，避免不同客户端复用编号时合并行。悬停图表时主动弹出数值，刷新时原位更新提示内容，移开鼠标后关闭；键盘方向键和回车选择时段继续可用。

## 统计口径

- 已结束请求按通道及请求编号去重，以结束时的本机日期归属。重试单独累计；保活、模型列表查询与未结束记录不计入分析，实时请求沿用独立入口。跨日请求只在结束日出现一次。
- 普通输入不含缓存读取和写入。总用量 = 普通输入 + 缓存读取 + 缓存写入 + 输出。思考用量为输出的子集，不再加进总量或费用。缓存命中率 = 有效请求的缓存读取总量 / 同批请求的总输入，按用量加权。
- 缺少字段保持未知。历史记录保留原数据，已知部分可汇总；存在缺失时显示部分统计，不把缺失伪造为零。Claude 未报告缓存写入时，已知总输入为下限、命中率为上限。
- 费用 = 各类用量乘对应每百万单位价格之和。公开价来自 models.dev，与 magpie 相同；按实际响应模型匹配，支持普通与长上下文档位、缓存写入 5 分钟 / 1 小时。未知价格或不足以计价的用量不计入金额，并显示未计费请求数。
- 新记录保存实际请求使用的供应商、Key 显示名称及用量，不保存凭据或正文。历史记录没有供应商身份时显示未记录，不能按现在选择的供应商倒推。

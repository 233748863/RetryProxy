# 可配置请求规则

2026-10-11：三项移植工作的第二项；完成验证后独立提交推送。

## 使用方式

在供应商编辑抽屉增加折叠的“请求规则”。每条规则可启停、按模型筛选、选择参数与操作；操作为设置、仅缺失时补齐、删除。按列表从上到下执行，可上移、下移。常用参数提供中文名称，文字值无需填写引号；高级参数可填写对象路径与 JSON 值。保存成功后新请求及后续重试使用新规则；关闭未保存草稿沿用现有确认流程。

```text
+-----------------------------------------------------+
| 编辑供应商                                          |
| 名称 / 地址 / 认证 / 主模型                          |
| > 请求规则                                          |
|   按列表顺序执行，模型条件匹配实际发送的模型          |
|   +-----------------------------------------------+ |
|   | [启用] 规则 1      [上移] [下移] [删除]        | |
|   | 生效模型 [留空表示全部，支持 *]                | |
|   | 参数     [思考强度 v]                          | |
|   | 操作     [设置 v]                              | |
|   | 值类型   [文字 v]   值 [high]                  | |
|   +-----------------------------------------------+ |
|   [添加规则]                                        |
| Key 列表                                            |
+-----------------------------------------------------+
```

沿用 MiSans 字体、现有深浅主题资源、4/8/12 像素间距与抽屉滚动。使用现有按钮反馈与折叠动画；不添加入场动画。英文标签换行，所有输入和排序按钮可用键盘访问。

## 转发与存储

- 供应商保存有序 `request_rules`，默认空列表，兼容 schema 7。草稿、配置克隆、相等比较和运行快照均包含规则；每个供应商最多 64 条。模型条件最多 256 字符，忽略大小写，`*` 匹配任意长度；空条件匹配全部。
- 在模型映射之后、缓存补齐之前执行，仅作用于 POST 生成接口（messages、responses、chat/completions）。参数路径用点分隔，最多 8 层、256 字符；只操作对象成员，不索引数组。参数值最多 16 KiB UTF-8、JSON 深度 32。保护模型、流式开关、对话内容、工具定义、会话标识和缓存标识，沿用已有功能管理这些字段。
- 定位后仅替换目标字节，保留其余正文的空白、数字精度、转义与字段顺序。未命中或无变化时复用原始正文；“仅缺失时补齐”保留已有的 null。缺少父对象时按需创建；父级为标量/数组、目标路径存在重复键时跳过该条。正文超过 8 MiB、深度超过 128、非对象 JSON、压缩或完整性签名时跳过规则，继续转发。日志仅记录改动与跳过条数，不记录路径、条件或参数值。
- 同一次尝试计划复用结果，重试不叠加改写；切换供应商从原始请求重新应用新供应商规则。保活使用通道规则，绑定供应商的独立准备任务在开始时保存规则快照；模型查询与 token 计数不应用。规则改变思考等级时诊断采用实际发送值。
